# Система управления книжным каталогом

**Практическая работа:** Веб-приложение для учета библиотечного фонда с текстовым поиском, детальным просмотром информации и функцией безопасного удаления книг.

Персональная ветка: `Zakharova`

---

## Реализованные требования (Моя зона ответственности)
* **CRUD-операции:** Безопасное удаление записей о книгах из системы.
* **Поиск:** Текстовый поиск по подстроке (название, автор, жанр) с сохранением состояния в URL.
* **Просмотр:** Детальная карточка книги с двухколоночным макетом и динамическим выводом физических экземпляров («Доступен» / «Выдан»).
* **Сохранение данных:** Реляционная база данных **SQLite3** (файлы в папке `data/`) вместо простых JSON-файлов.

---

## Структура проекта
* `app.py` — backend на Python (Flask), бизнес-логика поиска, загрузки карточки книги и удаления.
* `templates/` — HTML-шаблоны страниц (`base.html`, `index.html`, `book.html`).
* `static/styles.css` — стилизация таблиц, кнопок статусов, анимаций и модальных окон.
* `data/` — папка, в которой автоматически создается файл базы данных `books.db`.

---

## Этапы выполнения проекта по профессиональным ролям

### 1) Проектирование (Роль: Системный аналитик)
* **Входные данные:** Обработка ID книги для удаления/просмотра и текстовой строки `q` для поиска.
* **Выходные результаты:** Отфильтрованная по подстроке таблица книг, страница с метаданными конкретного издания и каскадное удаление данных (при удалении книги из `books` автоматически очищаются её копии из таблицы `book_items`).

### 2) Дизайн-макет (Роль: UI/UX Дизайнер)
* **Визуальные решения:** Двухколоночная сетка для страницы просмотра (информация — слева, экземпляры — справа).
* **Интерактивные элементы:** Цветовая индикация статусов («Доступен» — зеленый, «Выдан» — желтый). Оформление всплывающего окна удаления с размытием заднего плана (`backdrop-filter`).

### 3) Разработка
* **Frontend-разработчик:** Реализована HTML5-разметка страниц поиска и просмотра на Jinja2. Настроена CSS3-анимация: при клике на статус кнопка пружиняще сжимается на 6% (`transform: scale(0.94)`).
* **Backend-разработчик:** Написаны эндпоинты `@app.get("/")`, `view_book` и `delete_book`. Реализован подсчет доступных копий «на лету» и очистка поисковых запросов от лишних пробелов.
* **Интеграция:** Все модули связаны через Flask в единое монолитное веб-приложение.

### 4) Тестирование (Роль: QA-инженер)
* **Проверено:** Поиск по части слова в любом регистре, сохранение параметров в Query String при пагинации.
* **Проверено:** Стабильность каскадных связей в SQLite при удалении, валидация отображения стилей интерфейса на ПК.
